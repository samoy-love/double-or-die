## 1. Питч и позиционирование

**Твин-стик рогалик, где сложность выбираешь ты сам — ставками на самого себя.**

Перед каждой комнатой Туз выкладывает три карты-пари: «пройдёшь без урона?», «за 45 секунд?», «не поворачивая налево?». Берёшь сколько хочешь, ставишь фишки. Чем наглее пари — тем жирнее куш. Фишки — единственная валюта: апгрейды, лечение, воскрешение друга, доля заведения. Игра не наказывает тебя — ты наказываешь себя сам, и это смешно.

**Жанр:** твин-стик роглайт про азарт
**Игроков:** 1–4 (локально, онлайн, смешанно)
**Сессия:** 15 минут на забег (рабочий коридор 12–18)
**Платформы:** веб (с 0.1.0, публично с 0.5.0), PC Win/Mac/Linux и Steam Deck через Steam (с 0.10.0); мобильные и консоли — после 1.0
**Цена:** $9.99 / 599 ₽

**Референсы и что берём:**

| Игра              | Что берём                                               |
| ----------------- | ------------------------------------------------------- |
| Lethal Company    | смерть = контент (Дух), общая квота как источник паники |
| Fall Guys         | болванчики с характером, рэгдолл-унижение, косметика    |
| R.E.P.O.          | комедия из систем, а не из шуток                        |

## 2. Столпы дизайна

1. **Сложность — это ставка.** База лёгкая. Челлендж покупается добровольно, за жадность. Казуал играет расслабленно, задрот стакает четыре пари — в одной и той же комнате.
2. **Одна валюта давит на всё.** Фишки = прокачка = лечение = воскрешение = подмена карты = доля заведения. Каждая ставка ощущается физически.
3. **Пари меняют стиль игры, а не циферки.** Хорошее пари заставляет играть _иначе_. «Враги +10% HP» — не пари, это ползунок сложности.
4. **Комедия из правил.** Смешно, когда друг теряет 200 фишек, рефлекторно повернув налево. Игра производит истории, а не шутки.
5. **Читаемость превыше красоты.** За 0.2 секунды понятно, кто враг, что летит, куда бежать. Всё кодируется дважды — формой И цветом.
6. **Честное казино.** Ни реальных денег, ни лутбоксов, ни FOMO-таймеров. Мы продаём вкус азарта, а не эксплуатируем его.
7. **Никто не ждёт.** Мёртвый игрок продолжает играть (Дух). Ожидание — главный убийца кооп-вечера.
8. **Соло и кооп интересны по-разному, но одинаково.** Кооп живёт на втором игроке со своими интересами; в соло эту роль берёт Туз — ставит против тебя, торгуется, ведёт счёт между забегами. Соло не «кооп минус друзья».

```
МЕНЮ ──► ЗАБЕГ
           │
           ├── ЭТАЖ 1 (8 комнат) ──► БОСС «Рулетка»   ──► ДОЛЯ ЗАВЕДЕНИЯ
           ├── ЭТАЖ 2 (8 комнат) ──► БОСС «Бандит» ──► ДОЛЯ ЗАВЕДЕНИЯ
           ├── ЭТАЖ 3 (8 комнат) ──► БОСС «Колода»    ──► ФИНАЛ
           │
           └── ИТОГИ: ролик-статистика, Ключи, разблокировки
```

### Цикл одной комнаты (45–125 секунд)

```
1. ВЫБОР ДВЕРИ (5 сек)      — 2–3 варианта + аппетит одним нажатием
2. БОЙ (35–105 сек)         — карты пари лежат на арене и подбираются на бегу
   ├ Туз подбрасывает карту в середине схватки
   ├ «ЗАБРАТЬ» (LB)         — обналичить пари досрочно, одной кнопкой
   └ «УДВОИМ?» (3 сек)      — в слоу-мо, если все пари целы к середине
3. РАСЧЁТ (5 сек)           — выплата или провал с near-miss, реплика Туза
4. НАГРАДА (0–15 сек)       — магазин / апгрейд / событие, если дверь такая
```

**Бюджет времени: на не-боевые экраны ≤20% времени комнаты.** Отдельного стола ставок нет именно поэтому — он съедал до половины ранних комнат и тридцать раз за забег выдёргивал игрока из действия (§9.1).

## 7. Враги

Все — абстрактные геометрические формы с глазами. Двойное кодирование: форма + цвет. У каждой атаки — явный телеграф; контактные враги (Мошки, Вьюн) угрожают самим сближением, им телеграф не нужен.

Полные статы, автоматы состояний, правила агро и честности — в [DIFFICULTY.md §3 и §7](DIFFICULTY.md).

| Враг        | Форма             | Роль                                                |
| ----------- | ----------------- | --------------------------------------------------- |
| **Клин**    | треугольник       | таран по прямой без наведения — уклонение как навык |
| **Кирпич**  | квадрат           | держит дистанцию и простреливает её                 |
| **Фитиль**  | пульсирующий круг | взрывается, задевая и своих                         |
| **Гайка**   | шестиугольник     | медленный танк, при смерти делится на два Клина     |
| **Луч**     | отрезок           | лазер через арену, диктует позицию                  |
| **Мошки**   | рой точек         | душат числом                                        |
| **Забрало** | скобка            | щит спереди, требует захода за спину                |
| **Вьюн**    | Вьюн              | ворует фишки с пола и убегает                       |
| **Зеркало** | ромб              | повторяет движения игрока отражённо                 |

**Правило дизайна врагов:** каждый враг существует, чтобы давить на конкретный тип пари.
Клин выгоняет из безопасных зон → бьёт по «не заходи в красное».
Фитиль наказывает ближний бой → бьёт по «только ближний бой».
Вьюн ворует → бьёт по «собери все фишки».
Луч заставляет двигаться → бьёт по «не поворачивай налево».
Зеркало ломает мышечную память → бьёт по «дурацким».

## 8. Боссы

Каждый босс — азартный игрок и сам заключает пари против игрока.

### 8.1 Рулетка (этаж 1)

Арена — вращающееся колесо, разделённое на красные/чёрные секторы. По ободу скачет костяной шар.

- **Фаза 1:** пол вращается 15°/с, шар прыгает по секторам, при приземлении — ударная волна.
- **Фаза 2 (70% HP):** босс объявляет **встречную ставку**: «не попадёшь по мне 10 секунд». Выполнил свою ставку — лечится на 15%; сорвал — оглушён на 4 с. В коопе ставка объявляется против всей команды: попадание любого игрока её срывает.
- **Фаза 3 (35% HP):** вращение 40°/с, три шара, секторы поочерёдно проваливаются.
- **Пари этажа:** «убей Рулетку, стоя только на красном» ×4.

### 8.2 Бандит (этаж 2)

Слот-машина с рычагом. Каждые 8 секунд дёргает рычаг, три барабана выбрасывают комбинацию из символов, определяющую атаку.

| Символ | Атака                      |
| ------ | -------------------------- |
| 🔥     | волна огня по полу         |
| ⭐     | залп самонаводящихся звёзд |
| 🍒     | спавн Крошек               |
| 💀     | лазерная сетка             |

- Комбинация = три атаки подряд.
- **Три одинаковых = ДЖЕКПОТ:** босс обсыпается фишками, уязвим ×3 на 6 секунд, но арена заполняется фишками, и Спирали лезут их воровать (конфликт жадности и урона — идеальный момент для пари).
- **Пари этажа:** «убей Однорукого во время джекпота» ×5.

### 8.3 Колода (этаж 3, финал)

Босс тасует саму арену.

- **Фаза 1:** карты-солдаты (Клины в рубашке), стены из карт перестраивают арену каждые 10 с.
- **Фаза 2:** «тасовка» — все сущности на арене телепортируются местами, включая игроков.
- **Фаза 3:** босс раздаёт каждому игроку «руку» из 3 карт-пари принудительно, на 20 секунд, с огромными коэффициентами. Кон принудительных пари — за счёт заведения (при нуле фишек игрок рискует только наградой, не уходит в минус). Финал забега — это игра на всё, по построению.
- **Пари этажа:** «выиграй все три навязанных пари» ×8.

## 9. Система пари

### 9.1 Механика: ставки живут в бою, а не в меню

**Отдельного экрана стола ставок нет.** Карты пари лежат на арене и подбираются на бегу. Это решает главную проблему ритма: в прежней схеме игрока выдёргивали из действия около тридцати раз за забег, и не-боевые экраны съедали до половины ранних комнат.

```
Бой начинается ──► на арене лежат карты (количество зависит от состава)
      │
      ├─ подобрал карту   — пари принято, кон списан
      ├─ пробежал мимо    — карта тает через 12 секунд
      ├─ Туз подбрасывает новую карту в середине боя
      ├─ ЗАБРАТЬ (LB)     — обналичить своё пари досрочно
      └─ УДВОИМ? (Y)      — поднять ставку, добавив волну
```

**Сколько карт лежит: `игроков + 2`** → 3 / 4 / 5 / 6 на составах 1–4 (плюс одна на двери «жирный бой»).

Формула подобрана так, чтобы удержать две вещи одновременно. Каждому **хватает хотя бы на одну карту** — доступ к главной механике игры не может зависеть от того, кто быстрее бегает. И при этом карт **всегда меньше, чем хочется**: соло-игрок не может взять все и жадничает осознанно, а вчетвером хорошие карты становятся предметом гонки.

**Раскладка честная:** карты появляются разнесённо по арене, ни один игрок не оказывается систематически ближе к лучшей. Единственное исключение — Туз, который в соло кладёт их назло (§12А.4).

**Три источника динамики:**

**1. Карта — это место на арене.** Подобрать её физически рискованно: карта с жирным множителем лежит в простреливаемом углу, и добежать до неё — уже ставка. Выбор становится пространственным решением, срастаясь с главным глаголом твин-стика вместо конкуренции с ним. Игрок сам решает **когда** рискнуть, а не отвечает на вопрос игры.

**2. Туз подбрасывает карты по ходу боя.** Одна-две дополнительные карты падают в середине схватки, часто в неудобное место. Решения перестают быть разовыми и превращаются в поток: соблазн приходит тогда, когда уже жарко.

**3. «Забрать» — обналичивание досрочно.** Своё пари можно закрыть в любой момент одной кнопкой: **возвращается кон плюс половина той прибыли, что причиталась бы за победу**. Это превращает пари из пассивного ограничения в живое напряжение на весь бой: ты на одном сердце, «Без урона» ещё цело, идёт третья волна — забрать половину или дожать?

Обналичивается **только личное пари**. Командные ставки закрыть нельзя — в этом их риск и причина повышенного множителя; заодно это исключает возможность испортить куш всей группе одним нажатием.

Математика делает выбор настоящим: обналичивать выгодно, когда шанс дожать упал ниже примерно двух третей ([ECONOMY §9А](ECONOMY.md)). То есть кнопка права ровно тогда, когда ты в беде, и не права, когда всё под контролем.

**Потенциальная выплата на экране растёт** по мере выполнения пари — игрок видит, как набухает куш, и каждую секунду решает, хватит ли ему. «Забрать» и «Удвоим?» — два конца одной шкалы: снизить риск или поднять.

### 9.2 Что осталось на паузе

Опасным должен быть **поступок**, а не чтение. Поэтому под обстрелом живут только те решения, которые считываются мгновенно и нажимаются одной кнопкой:

| В бою (динамично)                                | На паузе (вдумчиво)       |
| ------------------------------------------------ | ------------------------- |
| подобрать карту — цвет и иконка читаются на бегу | магазин и апгрейды        |
| «Забрать» — одна кнопка, без чтения              | торг о доле заведения     |
| «Удвоим?» — слоу-мо 20%, `Y`/`B`                 | выбор двери               |
| —                                                | экран расчёта и near-miss |

Детали карты (полный текст условия) читаются удержанием кнопки — время при этом **замедляется**, так что любопытство не наказывается смертью, но и пауза не разрывает бой.

### 9.3 Прочие правила

- **Кон — три фиксированных тира** (`Скромно / Нормально / По-крупному`), выбираются **до входа в комнату**, на экране выбора двери: одно нажатие крестовиной задаёт аппетит на весь бой, и в схватке думать о размере уже не нужно. Значения живут в конфиге. **Кон никогда не превышает кошелёк — Туз в кредит не принимает.**
- **Стак:** коэффициенты перемножаются, выполнить надо все, кон общий. Всё или ничего. Надбавки за стак нет — перемножение уже удваивает ожидание ([ECONOMY §8](ECONOMY.md)).
- **«Удвоим?»:** при всех целых пари к середине боя Туз предлагает ×2 и добавляет волну. Время замедляется до 20% на 3 секунды: `Y` — принять, `B` или таймаут — отказ без штрафа. Длительность окна — в настройках доступности, режим «Спокойно» её удваивает.
- **Near-miss обязателен:** при провале показываем, насколько близко было («не хватило 4 секунд», «первый урон за 12 с до конца»). Почти-выигрыш — главный двигатель «ещё разок».
- **Провал:** кон уходит Тузу. Долга это не создаёт никогда — кон физически не может превысить кошелёк (§11).

### 9.4 Баланс категорий

Запреты («не делай X») ≤ **половины** стола. Остальное — «Трюки» и «Жадность», дающие позитивные цели. Игра не должна ощущаться сплошным «нельзя».

Каждая категория — свой цвет и иконка. Условие на карте — **максимум 5 слов**. Детали по удержанию кнопки.

## 10. Экономика

> **Все числа, формулы и обоснования — в отдельном документе [ECONOMY.md](ECONOMY.md).** Здесь только дизайнерские принципы; дублировать таблицы нельзя, они разойдутся.

### Три принципа

**1. Ставки щедрые, давит счёт от заведения.** Очевидное решение — сделать пари убыточными («дом всегда в плюсе») — здесь ошибочно: отрицательное матожидание превращает главную механику в наказание, игрок статистически проигрывает и перестаёт рисковать. Поэтому у всех пари **положительное матожидание**, а давление вынесено в долю заведения, которая растёт быстрее дохода.

Побочная выгода: балансный рычаг ровно один — кривая платы. Не нужно трогать двадцать четыре множителя, чтобы изменить сложность.

**2. Точка безубыточности `p = 1/M`** — единственная формула, которую игрок считывает интуитивно. Пари ×2 стоит брать, если справляешься чаще половины раз; ×3 — чаще трети. Целевые вероятности успеха подобраны на 5 процентных пунктов выше безубыточности, причём **чем наглее пари, тем выше отдача** — дерзость обязана вознаграждаться.

**3. Доля заведения — механизм принуждения к риску.** Игроки надёжно оптимизируют веселье из игр: рациональный игрок берёт ноль пари и делает вывод «скучно», и он прав — без ставок это посредственный твин-стик. Туз забирает фиксированную сумму в конце каждого этажа, и это **не кооп-механика, а общая**: в соло она единственный источник давления.

### Как именно наказывается осторожность

Не стеной, а отставанием. Осторожный игрок **гарантированно проходит первый этаж** — упереться в стену на старте было бы отвратительно для казуальной аудитории — и обычно гибнет на втором-третьем. За весь забег он покупает один апгрейд против четырёх и больше у играющего на ставках, входит в поздние бои слабым и без запаса сердец. Он проигрывает не бедности, а собственной трусости — и это ровно то чувство, ради которого игра сделана.

**Не заплатил** — этаж-штраф: следующий этаж начинается с проклятием и урезанным столом (2 карты вместо 3).

### Выбор кона — настоящее решение

Три тира не косметика: правильный ответ **меняется по ходу забега**. Пока ты в плюсе, оптимален размер по карману (критерий Келли даёт около 7% банкролла, и три тира ровно покрывают встречающийся в забеге диапазон). Как только отстаёшь от доли заведения, математика требует обратного — крупных ставок, потому что нужно догнать к сроку.

**Доля заведения сама порождает драматургию:** отстающий игрок математически прав, когда идёт по-крупному. Никакого скрипта, только арифметика.

### Потолок множителя

Урок Balatro: игрок должен хотя бы изредка доходить до абсурдных чисел, которые хочется заскринить. Стак из четырёх пари, «Молотилкаец» на длинной серии и два «Удвоим?» дают **×450**. Такой забег почти всегда кончается катастрофой, но существовать обязан; целевая частота задана числом в одном месте — [ECONOMY §9](ECONOMY.md).

### Защита от снежного кома

Три стока работают одновременно: рост цен ×1.5 за этаж, фиксированные тиры кона (абсолютный риск не растёт вместе с богатством), растущая плата. Контрольная метрика: верхний тир «По-крупному» не должен выбираться опытными игроками чаще 70% — иначе экономика сломана.

## 11. Долг и проклятия

**Провал пари долга не создаёт** — Туз не принимает в кредит, кон всегда в пределах кошелька. Единственный источник долга — **неуплата доли заведения**, да и то лишь если игрок выбрал этот вариант в торге (§12А.2). Правила:

1. **Долг не стакается.** Максимум одно проклятие одновременно.
2. **Погашается** прохождением следующей комнаты или дверью «Долговая яма».
3. **После провала Туз обязан предложить трамплин** — лёгкое пари ×1.5 в следующей комнате. Спираль неудач запрещена дизайном.

| Проклятие     | Эффект (одна комната)                          |
| ------------- | ---------------------------------------------- |
| Заём здоровья | −1 сердце                                      |
| Ускорение     | враги +20% скорости                            |
| Сухая рука    | рывок отключён                                 |
| Арест счетов  | фишки не подбираются, пока жив помеченный враг |
| Тьма          | экран сужен виньеткой                          |
| Комиссия      | −50% выплаты этой комнаты                      |

## 12А. Туз против тебя — соло-слой

**Задача.** Всё самое своеобразное в игре — ставка на напарника, ставка против него, Дух из мёртвых, торг за плату — работает потому, что рядом есть **второй игрок со своими интересами, чья судьба связана с твоей**. В соло этого агента нет, и игра честно превращается в крепкий, но обычный роглайт. Между тем большинство людей заходит в игру одни — даже в кооп-игры.

**Решение.** Туз перестаёт быть ведущим и становится **игроком за тем же столом**. Он не босс и не препятствие — он соперник с собственным кошельком, самомнением и историей отношений с тобой. Каждый кооп-крючок получает соло-аналог, где вторую роль исполняет он.

| Кооп-механика        | Соло-аналог                                           |
| -------------------- | ----------------------------------------------------- |
| Ставка на напарника  | **Ставка Туза** — он ставит против тебя               |
| Торг за общую плату  | **Торг с Тузом** о доле заведения                     |
| Воскрешение за фишки | **Последняя сделка** как настоящее пари, а не покупка |
| Отношения с друзьями | **Живой счёт** с Тузом, переходящий из забега в забег |

### 12А.1 Ставка Туза

Раз в два-три боя Туз **сам появляется на арене** — парящий цилиндр у края, — и бросает на пол **свою** карту: «Ставлю двести, что ты не дотянешь до третьей волны без урона».

**Он не мешает бою.** Рисуется в слое ниже боевых сущностей, полупрозрачен при перекрытии, не коллизится и неуязвим; пули проходят сквозь него — но он вздрагивает и огрызается. Злорадство даётся отзывчивостью, а не хитбоксом: перекрывать обзор в игре, где читаемость объявлена столпом, недопустимо. Собственная цветовая ниша (кремовый и угольный) выводит его из спектров и врагов, и игроков. Подброс карты телеграфируется за 0.5 секунды.

Он не диктует из-за кадра, а находится в бою вместе с игроком: комментирует происходящее вслух, хихикает над промахами, замолкает, когда ты близок к выигрышу. Соло-арена перестаёт быть пустой.

**В коопе он тоже приходит, но скромнее:** держится у края и уменьшается с ростом состава — вчетвером на арене и без него тесно, а ставит он там против всей команды. Соло он занимает столько места, сколько заслуживает единственный собеседник.

- Ставит он **свои фишки**, не твои. Выиграл ты — забираешь их. Выиграл он — забирает эквивалент из твоего кошелька.
- Отказаться можно (без штрафа), но он это запомнит и будет подкалывать.
- Условия берутся из того же каталога пари — новой системы не требуется, меняется только источник карты и направление выплаты.
- В коопе он ставит против всей команды — механика не конфликтует с кооп-режимом, а усиливает его.

Психологически это совсем другое чувство, чем обычное пари: там ты рискуешь **своим**, здесь есть шанс **обобрать его**. Появляется адресат злорадства.

### 12А.2 Торг о доле заведения

Не хватает на плату — вместо сухого «этаж-штраф» Туз предлагает выбор:

| Вариант                                                    | Цена                                |
| ---------------------------------------------------------- | ----------------------------------- |
| «Возьми вот это пари в следующей комнате — и мы в расчёте» | принудительное пари с высоким коном |
| «Продай мне апгрейд»                                       | обратный выкуп за половину цены     |
| «Иди в долг»                                               | проклятие на комнату                |

Это тот же эмоциональный момент, что переговоры в коопе — кто-то должен рискнуть, — только вторая сторона переговоров он.

### 12А.3 Последняя сделка — пари, а не покупка

Смерть в соло — самый слабый момент дизайна: раньше он был транзакцией («заплати 50% и получи проклятие»). В игре, которая целиком про ставки, **воскрешение обязано быть ставкой**.

Игрок умирает, время останавливается, Туз выкладывает три карты:

> «Одна раздача. Ставка — всё, что у тебя есть. Выбирай.»

Каждая карта — короткое испытание на 10–20 секунд, в которое игрок возвращается с одним сердцем: убить троих за десять секунд · продержаться пятнадцать секунд, не стреляя · дойти до двери, не получив урона.

- **Выполнил** — полное воскрешение, здоровье восстановлено, долгов нет.
- **Провалил** — забег окончен, кошелёк у Туза.
- Один раз за забег. Отказаться можно — тогда забег заканчивается сразу, но фишки остаются в статистике.

Худший момент забега превращается в самый памятный, и делает это средствами самой игры.

### 12А.4 Живой счёт: соперничество длиннее одного забега

Сальдо из «Счёта с Тузом» (§19) — не только статистика, но и **состояние отношений**, влияющее на поведение:

| Ты в минусе (он выигрывает)      | Ты в плюсе (обыгрываешь его)                     |
| -------------------------------- | ------------------------------------------------ |
| расслаблен, щедр на коэффициенты | нервничает, коэффициенты жёстче                  |
| подкалывает добродушно           | язвит, начинает играть грязно                    |
| Ставки Туза скромные             | Ставки Туза крупные и злые                       |
| карты кладёт в удобные места     | **кладёт карты в самые опасные точки арены**     |
| —                                | изредка подкидывает лишнего врага «для интереса» |

Последняя строка — важная: **он лично решает, где будут лежать карты**, и когда начинает проигрывать, кладёт их туда, куда идти страшно. Динамика соло-боя меняется вместе с отношениями, без единой новой системы.

Это даёт соло-игроку то, что кооп получает от друзей, — **дугу отношений, которая переживает отдельный забег**, и повод вернуться завтра: отыграться.

### Стоимость

Слой почти целиком переиспользует существующие системы: Ставки Туза — тот же движок пари, торг — три опции в уже существующем моменте, счёт — несколько чисел в сохранении и словарь реплик. Отдельной разработки требуют только испытания Последней сделки. Это признак верного дизайна: сильная механика собирается из уже построенного.

## 13. Дух: смерть как контент

Умерший игрок **не выбывает и не смотрит в потолок**. Он становится Духом за столом Туза.

| Может                                                         | Не может           |
| ------------------------------------------------------------- | ------------------ |
| Летать по арене без коллизий                                  | Наносить урон      |
| Видеть точки спавна за 2 с до появления и скрытые телеграфы   | Подбирать фишки    |
| Подсвечивать точку арены (пинг)                               | Влиять на физику   |
| **Ставить фишки на живых** — включая ставки на их провал (×3) | Тратить в магазине |
| Воскреснуть сам, накопив цену воскрешения                     | —                  |

**Почему это работает:** мёртвый остаётся в игре, продолжает принимать решения, и у него появляется собственная — часто противоположная — цель. Это самый плотный источник криков на диване и в голосовом чате.

Соло-аналог смерти — **«Последняя сделка»** (§12А.3): не покупка воскрешения, а настоящее пари на всё, что у тебя есть, с коротким испытанием вместо оплаты.

## 14. Кооп и социальный слой

**1–4 игрока.** Один экран, фиксированная камера, арена растёт на +8% за каждого игрока сверх первого. Сплит-скрина нет ни в каком виде — это ключ к простоте и онлайна, и локальной игры.

Масштабирование сложности и экономики по числу игроков — в [DIFFICULTY.md §5](DIFFICULTY.md) и [ECONOMY.md §11](ECONOMY.md). Коротко: врагов становится больше (но они не «баффаются» — иначе ломается выученное время убийства), длительность комнаты не меняется, доход на игрока остаётся в целевых пределах (число задано в ECONOMY §11).

- **Drop-in/drop-out:** удержал `A` на втором геймпаде 1 секунду — подтверждающая плашка — в игре со следующей комнаты (случайное нажатие на лежащем геймпаде не срабатывает). Онлайн-игрок подключается по приглашению Steam.
- **Кошельки раздельные.** Общая только **Доля заведения** — скидываются как договорятся, и это отдельный источник переговоров и паники. Не наскребли — этаж-штраф получает вся команда (наказание общее, чтобы переговоры были всерьёз).
- **Воскрешение:** подойти к телу и держать `Y` 3 секунды (подсказка Туза над телом), платит воскрешающий.
- **Карты на арене — предмет гонки.** Их `игроков + 2`: каждому хватает на одну, но хороших на всех не напасёшься. Кто добежал — того и пари, и напарники это видят. Отсюда бесплатно рождается динамика, которой не дало бы общее меню: спор за жирную карту, подрезание, «не трогай, она моя», добровольная уступка союзнику, который отстаёт по деньгам. Экрана выбора в коопе нет вовсе — а с ним исчезает и проблема «трое ждут, пока один читает».
- **«Забрать» — личное.** Каждый обналичивает своё пари сам; командные закрыть нельзя, поэтому испортить куш всей группе одним нажатием невозможно. Но кричать «НЕ ЗАБИРАЙ, ДОЖМЁМ!» это не мешает.
- **«Удвоим?» принимает любой — за всех.** Туз обращается к столу, и первый согласившийся поднимает ставку всей команде. Это лучший источник воплей на диване («ЗАЧЕМ ТЫ СОГЛАСИЛСЯ?!») и одновременно то, что в публичных лобби отключается хостом вместе со ставками против напарника.
- **Раскладка Духа:** LS — полёт, RT — пинг-подсветка точки, A — ставки Духа на живых, удержание Y у своего тела — самовоскрешение при накопленной цене.
- **Дружественного огня нет.** Но толкаться можно, и в пари «не заходи в красную зону» это оружие.

### Саботаж: осознанная развилка

Столкновения игроков плюс ставка против напарника дают очевидную стратегию — **толкнуть его в красную зону и забрать выплату**. С друзьями на диване это лучший момент вечера. Со случайными людьми онлайн это причина выйти из игры.

Решение — не запрещать, а разделить контексты:

| Контекст                             | Поведение                                                                                                                        |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| Лобби «только друзья» (по умолчанию) | саботаж разрешён полностью, это фича                                                                                             |
| Публичное лобби                      | ставки против напарника выключены хостом по умолчанию; толкание остаётся, но выгоды не даёт                                      |
| Метрика-сторож                       | если после ставки-против сессии обрываются чаще обычного — механика режется независимо от того, насколько она нравится на бумаге |

### Общение (критично для онлайна, где нет дивана)

Голосовой чат мы не пишем — используем Steam Voice. Но игра должна быть играбельна и без него:

- **Колесо пингов** (удержание `RB`): «Иду сюда» · «Помоги» · «Ставлю на тебя» · «Не двигайся» · «Я на мели» · «Удваиваем!»
- **Эмоции** (крестовина): помахать · поржать · поплакать · «деньги-деньги» · поклон
- **Общий HUD пари:** активные пари всех игроков видны всем, компактной лентой сверху.
- **Настройки по умолчанию:** лобби «только друзья», ставки против напарника можно отключить хостом (для игры со случайными людьми).

## 15. Versus: против друг друга

**Параллельный заезд.** Все игроки проходят одинаковые комнаты с одинаковыми картами пари (общий сид), каждый на своей копии арены. Экран делится, но арены маленькие и читаемые. Побеждает тот, кто заработал больше за этаж.

**Грязные деньги.** За фишки можно подкинуть сопернику врага (30), проклятие на комнату (60), украсть его карту пари (80).

**Финальная дуэль.** После третьего этажа — общая арена, весь банк на кону, PvP до трёх сердец. Пари остаются: «убей соперника, не поворачивая налево» ×5.

## 16. Генерация и кривая сложности

**Всё от одного сида забега.** Отдельные детерминированные потоки RNG: `layout`, `waves`, `bets`, `loot`, `shop`. Разделение потоков обязательно — иначе изменение одной системы ломает сиды всех остальных.

**Арена:** выбирается один из 12 рукотворных шаблонов расстановки колонн, зеркалится/поворачивается случайно. Полностью процедурная геометрия отвергнута: рукотворные шаблоны читаемее и дешевле в отладке.

**Волны:** бюджетная система. Комната имеет бюджет очков угрозы, волна набирается из доступных на этаже врагов до его исчерпания. **Формулы, стоимость каждого врага и масштабирование по числу игроков — в [DIFFICULTY.md](DIFFICULTY.md).**

**Ввод новых врагов:** не больше одного нового типа за две комнаты. Первое появление врага — всегда в одиночку и с замедленным телеграфом (обучение без туториала).

## 17. Туз

Ведущий, антагонист и маскот. Внешне — **парящий цилиндр с глазами и белыми перчатками**, тела нет. Появляется у стола, комментирует расчёт, шепчет «Удвоим?».

**Тон:** обаятельный жулик. Болеет за игрока, обожает его жадность, издевается над трусостью нежнее, чем над глупостью. Реплики короткие (≤10 слов), без пошлости.

**Он не рассказчик, а участник.** В соло Туз — второй игрок за столом со своим кошельком и самомнением: ставит против тебя, торгуется, злорадствует и нервничает, когда проигрывает (§12А). Это несущая роль, а не украшение: без неё соло-режим лишается всей социальной драматургии, на которой держится кооп.

**Система реплик:** банк из ~200 барков с контекстными тегами (`first_bet`, `bet_won_big`, `bet_lost_stupid`, `near_miss`, `player_cautious_3_rooms`, `ghost_bet_against_friend`, `double_accepted`, `debt`, `boss_intro`). Без повторов в рамках забега.

**Примеры:** «Смелое решение. Обожаю смелые решения.» · «Дом всегда в плюсе. Но ты попробуй.» · «Налево. Ты повернул. Налево.» · «Три комнаты без ставки. Ты вообще играть пришёл?» · «Твой друг поставил против тебя. Я лишь посредник.»

**Голос:** тарабарщина в стиле Banjo-Kazooie — тональные бормотания под настроение реплики. Дёшево, характерно, **не требует переозвучки при локализации**.

### 17А. Комедия: откуда она берётся

Тег «весёлая» стоит в описании игры, а столп №4 требует комедии из правил. Но заявить смешное мало — нужно назвать источники.

**Главное правило: юмор играется телом, а не текстом.** Написанные шутки стареют с третьего забега, раздуваются при переводе на семь языков и требуют переводчика с чувством юмора. Поведение работает без слов, попадает в клипы и не устаревает.

#### Туз как физический комик

Он не диктор, а актёр на сцене. Его тело — главный носитель юмора:

| Ситуация                            | Что он делает                                                |
| ----------------------------------- | ------------------------------------------------------------ |
| Три комнаты без единого пари        | демонстративно зевает, полирует перчатки, изучает свои ногти |
| Игрок проваливает пари              | подпрыгивает от радости, хлопает в ладоши                    |
| Игрок вот-вот выиграет крупно       | отворачивается и делает вид, что занят чем-то другим         |
| Игрок обналичивает на 90% прогресса | молча показывает большой палец вниз                          |
| Особенно нелепая смерть             | аплодирует стоя                                              |
| Игрок в плюсе по сальдо             | нервно поправляет цилиндр, суетится                          |
| Джекпот у Бандита                   | закрывает глаза перчатками                                   |

#### Четыре источника, кроме него

1. **Эпитафии на экране смерти**, собранные из реальных данных забега: «Здесь лежит тот, кто повернул налево», «Умер богатым — всё осталось мне», «Три сердца, шесть пари, ноль сожалений». Не повторяются, потому что берутся из того, что действительно произошло.
2. **Правила заведения на загрузочных экранах.** «Правило 4. Заведение не отвечает за ваши решения». «Правило 11. Смерть не освобождает от обязательств». «Правило 19. Не поворачивайте налево. Мы не обязаны объяснять».
3. **Названия достижений** — дешёвое и долгоживущее место для юмора: «Соскочил» (обналичить на 95% прогресса), «Левша» (провалить «не поворачивай налево» десять раз), «Дом всегда в плюсе» (уйти в минус на тысячу).
4. **Косметика-шутки:** ведро вместо шляпы, корона из фольги, монокль, глаза-доллары. Отдельно — **цилиндр как у Туза**: надеваешь, и он весь забег ведёт себя оскорблённо.

#### Границы

- **Туз смеётся над ситуацией и над собой, а не над игроком.** Правило дозировки: чем сильнее игрок пострадал, тем мягче реплика. После третьей смерти подряд издёвка перестаёт быть смешной и становится причиной закрыть игру.
- **Ни одной шутки в обучающих подсказках.** Там текст должен работать, а не веселить.
- **Юмор не мешает читаемости.** Анимации Туза живут в слое ниже боевых сущностей и не перекрывают снаряды.

### Туз помнит

Между забегами сохраняется небольшой профиль привычек игрока: любимые пари, самые частые провалы, склонность к осторожности или наглости, счёт «выиграно/проиграно» лично против него. Туз на это ссылается:

- «Снова «без урона». В прошлый раз это стоило тебе сто двадцать.»
- «Ты не поворачивал налево четыре забега подряд. Я начинаю подозревать, что тебе нравится.»
- «За неделю ты отдал мне восемьсот фишек. Спасибо.»
- «Осторожничаешь третий забег. Я скучаю по прежнему тебе.»

Стоит это десяток чисел в сохранении и один словарь реплик, а даёт ощущение, что у игрока есть **отношения с персонажем**, а не с генератором заданий. Для игры, где один и тот же цикл повторяется десятки раз, это один из самых дешёвых способов удержания. Реализуется в 0.8.0 вместе с метой.

## 18. Мета-прогрессия

Только разнообразие, **никакой постоянной силы**. Игра не должна становиться легче — она должна становиться шире.

**Валюта:** ключи. 1 ключ за каждые 5 выполненных пари + 3 за победу над боссом.

| Стоимость | Разблокировка                                        |
| --------- | ---------------------------------------------------- |
| 5         | новая карта пари в колоду Туз (всего 18 таких)       |
| 15        | новое оружие (Обрез → Кий → Молотилка → Кость)       |
| 10        | косметика: шапки, глаза, цвет, след рывка, вид фишек |
| 25        | недельные мутаторы                                   |
| 40        | VIP-этаж (4-й, открывается после первой победы)      |

**Первые 3 забега ничего не разблокируют кроме базовых пари** — новичок не должен тонуть в меню.

## 19. «Счёт с Тузом» — статистика игрока

Экран прогресса, доступный из главного меню. Для рогалика это не служебная таблица, а **контент**: игрок возвращается посмотреть, как растут цифры, и находит в них поводы для нового забега.

Тематическая рамка — **гроссбух Туза**, а не «Statistics». Он и так помнит привычки игрока (§17), поэтому статистика естественно оформлена как его записи о вас: «за вами числится», «ваше любимое пари», «ваше проклятие». Тот же источник данных, что у системы реплик.

### Что показывается

| Раздел                  | Содержание                                                                                                                                                                            |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Баланс с заведением** | всего заработано фишек · всего отдано Тузу · итоговое сальдо (главное число экрана)                                                                                                   |
| Забеги                  | сыграно · побед · доля побед · самый долгий · средняя длина                                                                                                                           |
| **Лучший куш**          | самая жирная выплата одной ставкой: множитель, сумма, какое пари, когда — **скриншотопригодный блок**                                                                                 |
| Пари                    | взято · выполнено · провалено · доля. **Разбивка по каждому из 24:** сколько раз брал, сколько выиграл → автоматически выводятся «ваше любимое пари» и «ваше проклятие» (худшая доля) |
| «Удвоим?»               | предложено · принято · выиграно — показывает, трус ты или нет                                                                                                                         |
| Смерти                  | кто убивал чаще всего, на каком этаже и в какой комнате обрываешься обычно                                                                                                            |
| Арсенал                 | любимое оружие, самые частые апгрейды                                                                                                                                                 |
| Кооп                    | воскрешений сделано и получено · ставок на друзей · **ставок против друзей** · выиграно из мёртвых Духом                                                                              |
| Дейли                   | участий, лучшее место, серия дней                                                                                                                                                     |
| Разблокировки           | сколько из скольких открыто, что ближайшее                                                                                                                                            |

### Правила

- **Отвечает Туз, а не таблица.** У каждого раздела — одна его реплика по твоим числам: «Восемьсот фишек за неделю. Я тронут», «Ты берёшь «Без урона» чаще всех и проигрываешь его чаще всех».
- **Никакого сравнения с другими игроками** на этом экране — он про личный прогресс. Соревнование живёт в дейли-таблицах.
- Работает офлайн и в вебе; на Steam синхронизируется Steam Cloud между устройствами.
- Данные те же, что питают «Туз помнит» (§17) — одна структура в сохранении, не две.
- Экран показывается кнопкой из главного меню и одной строкой упоминается в итогах забега («сальдо изменилось на −120»).

## 20. Дейли и еженедельное

- **Дейли:** сид от даты, одна попытка, глобальная и дружеская таблица. Результат валидируется на сервере переигрыванием лога инпутов (см. [SECURITY.md §5](SECURITY.md)).
- **Еженедельный мутатор:** «Все пари дурацкие» · «Один этаж, тройная награда» · «Врагов вдвое, здоровья вдвое» · «Туз пьян: коэффициенты случайны».
- **Реплеи:** любой забег сохраняется как лог инпутов (~50 КБ), можно пересмотреть и поделиться кодом.

## 21. Арт-дирекшн

**Стиль:** плоские векторные формы, толстая обводка (4 u), сочная палитра. Всё рисуется кодом — растровых ассетов в геймплее нет.

### Иерархия читаемости

При четверых на арене одновременно: 4 игрока с нимбами, 6 карт, россыпь фишек, снаряды, алые телеграфы и Туз. Без явного порядка приоритетов «снаряды ярче всего» и «луч карты виден сквозь толпу» конкурируют за одну и ту же яркость.

**Порядок слоёв и потолок яркости, сверху вниз:** снаряды → телеграфы → игроки → карты и их лучи → Туз → фишки → декор → фон.

**Категория пари читается формой и иконкой, а не цветом.** У всех карт единая кремовая «карточная» подложка; категорию несут иконка и форма рамки. Красить карты в категорийные цвета нельзя — они совпадают с цветами игроков и фишек, а главную сущность недопустимо красить в то, от чего её надо отличать.

| Роль                | Цвет                                                                                                                                                                                                                                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Фон                 | глубокий сине-фиолетовый `#1a1033`                                                                                                                                                                                                                                                                       |
| Карты пари          | кремовая подложка `#F2E4C4`, категория — иконкой                                                                                                                                                                                                                                                         |
| Туз                 | кремовый и угольный, вне спектров игроков и врагов                                                                                                                                                                                                                                                       |
| Пол арены           | `#251845` с сеткой                                                                                                                                                                                                                                                                                       |
| Игрок 1 / 2 / 3 / 4 | оранжевый `#FF9330` / голубой `#3FBFFF` / зелёный `#5FE85F` / розовый `#FF6FB5` — P1 сдвинут с жёлтого: он сливался с золотом фишек в худший момент читаемости (джекпот). Все пары «игрок/враг/фишка/телеграф» проходят ΔE-проверку на F2; игроков от врагов дополнительно отделяют белая обводка и нимб |
| Враги               | красно-фиолетовый спектр `#FF3B6B` → `#B03FFF`                                                                                                                                                                                                                                                           |
| Фишки               | золото `#FFC531`                                                                                                                                                                                                                                                                                         |
| Опасность/телеграф  | алый `#FF2D2D` с пульсацией                                                                                                                                                                                                                                                                              |
| Пари по категориям  | стиль-синий · темп-оранжевый · пространство-зелёный · жадность-золотой · трюки-бирюза · дурацкие-фуксия                                                                                                                                                                                                  |

**Персонажи** — желешки-капли с большими глазами. Глаза следят за прицелом, жмурятся от урона, наглеют при ставке ×4. Squash-and-stretch на всём.

**Правило контраста:** снаряды всегда светлее и ярче всего остального на экране. Игрок всегда различим в толпе (обводка своим цветом + постоянный «нимб»).

**Карты пари против фишек — разный визуальный класс.** И то и другое подбирается с пола, поэтому путать их нельзя: фишки мелкие, золотые, россыпью; карты крупные, окрашены по категории, с иконкой и **вертикальным лучом света**, который виден сквозь толпу даже вчетвером на полной арене. Луч гаснет за 3 секунды до истечения карты — предупреждение без интерфейса.

## 22. Аудио

- **Музыка:** электросвинг с казино-перкуссией, три слоя (спокойный / бой / удвоение), кроссфейд по интенсивности. Отдельная тема на босса.
- **Звук как информация:** каждое пари имеет свой звук взятия, тика прогресса, успеха и провала. Провал — звон разбитого стекла + падающая нота. Успех — каскад фишек.
- **Новые механики обязаны звучать** — часть из них игрок должен считывать, не глядя на HUD:

| Событие               | Звук                                                                    |
| --------------------- | ----------------------------------------------------------------------- |
| Подбор карты          | шелест колоды и щелчок — **явно не «монетка»**, иначе путается с фишкой |
| «Забрать»             | короткий кассовый аккорд и обрыв тика прогресса                         |
| Появление Туза        | шорох и его смешок — пространственный сигнал «сейчас будет карта»       |
| Подброс карты         | свист и шлепок о пол, работает как телеграф                             |
| Карта вот-вот истлеет | угасающий звон за 3 секунды до конца                                    |

- **«Удвоим?»** — сердцебиение и приглушение всей музыки.
- **Дакинг:** реплики Туза приглушают музыку на 6 дБ.
- Реализация — Web Audio API напрямую, процедурная генерация части SFX (экономит вес и даёт вариативность).

## 23. Онбординг: первые 10 минут

| Время | Что происходит                                                                                                             |
| ----- | -------------------------------------------------------------------------------------------------------------------------- |
| 0:00  | Меню — одна кнопка «Играть». Никакого выбора персонажа/сложности                                                           |
| 0:10  | Комната 1: пустая арена, три мишени. Учит движению и стрельбе за 15 секунд, без текста                                     |
| 0:30  | Туз: «Первая ставка — за счёт заведения. Пройди без урона — 30 фишек твои». **Бесплатная ставка** учит ядру игры без риска |
| 1:30  | Первая настоящая раскладка: карта лежит прямо на пути, не заметить невозможно                                              |
| 2:30  | Принудительно выгодный момент «Забрать» с подсказкой — механика показывается на выигрышном примере                         |
| 3:00  | Вторая дверь: здесь впервые показывается аппетит                                                                           |
| 3:00  | Первая лавка. Первый апгрейд                                                                                               |
| 5:00  | Первое «Удвоим?» — принудительно предложено в лёгкой комнате                                                               |
| 8:00  | Первый провал (по статистике почти неизбежен) → near-miss экран → трамплин                                                 |
| 12:00 | Босс Рулетка                                                                                                               |
| 15:00 | Итоги: «Ты потерял 120 фишек на поворотах налево». Скриншот. «Ещё разок»                                                   |

**Правило:** ни одного модального окна с текстом длиннее одной строки. Всё объясняется через действие и реплики Туза.

## 25. Решения, которые не пересматриваются

Правила, за которые уже заплачено расчётом. Менять — только с новым обоснованием.

| Решение                                       | Почему так                                                         |
| --------------------------------------------- | ------------------------------------------------------------------ |
| Название `Double or Die` не переводится       | одно имя во всех языках и материалах                               |
| Аппетит — три фиксированных тира, не ползунок | ползунок на геймпаде это 19 щелчков                                |
| 1–4 игрока, один экран, без сплит-скрина      | фиксированная камера делает кооп и онлайн дешёвыми                 |
| Пари имеют **положительное** матожидание      | убыточные ставки превращают главную механику в наказание           |
| Доля заведения обязательна во всех режимах    | единственный источник давления; без неё игрок сам выключает игру   |
| Провал пари не создаёт долг                   | кон не превышает кошелёк, иначе появляется фрирол                  |
| Надбавки за стак нет                          | доминирование структурно и сдерживается лимитом кона и числом карт |
| Онлайн — версия 0.9.0, до релиза              | без него потолок продаж принципиально ниже                         |
| Запреты ≤ половины раскладки                  | иначе игра ощущается сплошным «нельзя»                             |
| Слоу-мо — соло-механика                       | в lockstep один игрок не может тормозить лобби                     |

## Питч в одну строку

**Твин-стик роглайт, где во время боя ты подбираешь с арены карты-пари: «пройду без урона», «за 45 секунд», «не поворачивая налево». Чем наглее пари — тем жирнее куш. Проигрываешь ты только самому себе.**

## Ключевые решения (принятые, не обсуждаются без веской причины)

1. **Детерминированная симуляция с первой строки кода.** Фиксированный тик, fixed-point математика, ноль `Math.random()` в логике. Это даёт бесплатно: реплеи, дейли-забеги, античит, golden-тесты, Monte-Carlo балансировку и открытую дверь в онлайн.
2. **Игра рендерится процедурно.** Ни одного растрового ассета в геймплее → патчи весом в мегабайты, нет художника в критическом пути, а плейсхолдер и финал делаются одним конвейером: круг становится желешкой правкой параметров, а не заменой файла.
3. **Симуляция не знает про рендер, инпут и сеть.** Чистый TS-модуль без зависимостей. Это цена портируемости на консоли в будущем.
4. **Ничего не режем — раскладываем по версиям.** Каждая минорная версия играбельна и выпускаема, поэтому остановка на любой ступени оставляет законченную игру. Если давление всё же возникнет, режется контент (число пари и боссов), но никогда не системы.
5. **Честное казино.** Ни реальных денег, ни лутбоксов, ни FOMO-таймеров. Столп дизайна и страховка рейтинга.

## Статус

**Версия 0.1.0 «Скелет» — ворота пройдены.** Детерминированное ядро, клиент, headless-раннер и инструменты агента в `main`. CI подтверждает главное: одинаковые хеши состояния на Windows, macOS и Linux.

Выкатка на `die.samoy.love` подготовлена, но не сделана: ждёт трёх вещей, доступных только владельцу — DNS-записи, сертификата и секретов репозитория. Что именно и в каком порядке — в [DEPLOY.md](DEPLOY.md).

Следующий шаг — **0.2.0 «Тир»**: доказать, что в бой приятно играть сам по себе.

Условия проекта: соло-разработка с ИИ-ассистентом, время не ограничено, цель — игра для друзей и заработок на релизе. Steam-выплаты доступны.

## Как это разрабатывается

Разработка идёт в браузере через `npm run dev` — самый быстрый цикл итераций. Веб-сборка при этом остаётся полноценной целью выпуска: другу проще отправить ссылку, чем `.exe`. Оболочка Electron и интеграция Steam появляются в 0.10.0, когда становятся нужны — это добавление, а не переписывание.

Основной инструмент проверки — **headless-раннер симуляции** (`npm run sim`): чистый Node, JSON в stdout, детерминированно, без графики. Браузер нужен только для визуальных вопросов. Подробности — в [DEVLOOP.md](DEVLOOP.md).

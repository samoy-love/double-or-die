# dev-alpha

Внутренние версии. Играет только разработчик и агент.

## 0.1.0 «Скелет»

**Цель:** доказать детерминизм и дать агенту возможность управлять игрой без единого клика. Геймплея нет — вся ценность в фундаменте, который невозможно заложить позже.

### Репозиторий и окружение [Ф]

- Приватный репозиторий GitHub, работа через PR. **Защита ветки машиной не включена:** GitHub не даёт её приватным репозиториям без платного тарифа, поэтому правило держится дисциплиной и проверяется на ревью. Варианта два — оплатить тариф или открыть репозиторий; до тех пор это известная дыра, а не забытая строка
- Монорепозиторий: `packages/sim`, `shared`, `client`, `tools`
- Vite + TypeScript strict, ESLint, Prettier
- **Линтер границ модулей:** `sim` не импортирует ничего; `window`/`document`/`Math.random`/`Date.now` в `sim` — ошибка сборки
- Сканер секретов в `pre-commit`: приватные ключи, токены с узнаваемым префиксом и файлы окружения не уезжают в историю. Проверяются только добавляемые строки — хук, ругающийся на давно лежащий текст, отключают через неделю
- `.env` и `.env.*` в `.gitignore`. Образца `.env.example` нет намеренно: своих переменных окружения у игры сейчас нет вовсе, и пустой образец врал бы о наличии настроек
- `.claude/launch.json` — конфигурация запуска для агента
- CI: `lint → typecheck → unit → golden → build` на матрице win/mac/linux

### Ядро симуляции [Я]

- Fixed-point Q16.16: `add`, `sub`, `mul`, `div`, `sqrt`
- **`mul`/`div` через hi/lo-разбиение** — произведение двух Q16.16 не влезает в 53-битную мантиссу
- Таблицы `sin`/`cos` на 4096 значений с интерполяцией, `atan2`
- Анализ диапазонов величин, закреплённый тестом `tests/ranges.test.ts`. Вывод: **Q24.8 не нужен нигде**. Позиции и скорости лежат в Q16.16 с запасом, а квадраты позиций в него не помещаются в принципе — их считает `length()`, уходя в обычные числа
- RNG `xoshiro128**`, **шесть независимых потоков**: `layout`, `waves`, `bets`, `cards`, `loot`, `shop`
- Фиксированный тик 60 Гц с аккумулятором, отвязанный от кадра
- Состояние SoA на типизированных массивах, предаллокация под потолки
- Снимок и восстановление состояния
- Хеш состояния FNV-1a
- `InputFrame` с 16-битной маской ([TECH.md §6](TECH.md))
- Запись и воспроизведение лога инпутов, RLE-сжатие
- Инварианты в dev-сборке (`[DOD:INVARIANT]`)

### Клиент [К]

- Рендер на Canvas 2D с пулами объектов. WebGL2 с батчингом — в 0.2.0, вместе с сочностью, ради которой он и нужен: тянуть тысячи частиц в 0.1.0 нечем и незачем, а интерфейс рассчитан на подмену бэкенда
- Интерполяция между тиками (поддержка 120/144 Гц бесплатно)
- **Палитра в одном модуле** — захардкоженный цвет в коде отрисовки ловится линтером
- Слой ввода: Gamepad API, клавиатура, мышь → нормализация в `InputFrame`
- Радиальная мёртвая зона 0.18, буфер ввода 6 кадров, coyote-время 4 кадра
- Игрок-квадрат: движение, рывок-заглушка
- Отладочный оверлей: FPS, номер тика, хеш состояния, версия сборки

### Доставка сборки [Ф]

- Версия и git-SHA зашиваются в билд, видны в оверлее и в баг-репортах
- Контент-хешированные имена файлов
- Service worker с фоновым обновлением
- **Проверка версии при запуске:** клиент сравнивает свою версию с серверной
- Ненавязчивый индикатор «доступна новая версия», применение при следующей перезагрузке
- Предыдущая сборка остаётся доступной по адресу — механизм отката
- nginx на VPS раздаёт `dev.die.samoy.love` через deploy-kit: длинный кеш на хешированных файлах, `no-cache` на `index.html` и `no-store` на манифесте версии ([DEPLOY.md](DEPLOY.md))

> Без этого агент и разработчик будут ловить фантомные баги из устаревшего кеша, а версия в баг-репорте станет бессмысленной.

### Инструменты [И]

- Headless-раннер `npm run sim`: `--seed`, `--runs`, `--bot`, `--json`, `--out`, `--determinism-check`, `--replay`, `--assert-hash`, `--scenario`, `--golden`
- Перезапись эталонов только явным `--record-golden ... --rebaseline`: молчаливый ре-бейзлайн превращает golden-тест в подтверждение любого поведения
- Боты `idle` и `random`
- `window.__DOD__` — **только в dev-сборке**: `ready`, `newRun`, `tick`, `state`, `hash`, `events`, `input`, `perf`, `stable`
- Навигация по URL-параметрам: `seed`, `players`, `autopause`, `stable`, `debug`. **`debug=1` включает оверлей, а не `__DOD__`:** отладочный интерфейс даёт полный контроль над симуляцией и в релизе является читом, поэтому вырезается сборкой навсегда
- Протокол консоли `[DOD]` / `[DOD:ERROR]` / `[DOD:INVARIANT]` в одном модуле. Нарушенный инвариант останавливает цикл и печатает сид с тиком, но не бросает исключение наружу: упавший rAF унёс бы с собой рендер и отладочный интерфейс, и агент увидел бы застывшую картинку вместо причины
- Формат сценариев и раннер
- `npm run bench`, `npm run check`

### Тесты [Т]

- Юнит: fixed-point математика, RNG, границы диапазонов
- **20 golden-реплеев × 3 ОС**, сверка хеша каждые 600 тиков, составы 1–4 игрока
- Сценарии: формат, раннер и первые пять
- Отсутствие аллокаций: 10 000 тиков без роста кучи
- **Прод-бандл не содержит отладочного API** — функциональная проверка, не поиск по тексту
- Бенч ядра `npm run bench`: тик, хеш, снимок и восстановление с запасом к бюджету кадра. Нагрузочный бенч рендера (2000 частиц + 200 болванок) — в 0.2.0, вместе с частицами
- Линтер палитры: захардкоженный цвет вне `palette.ts` валит сборку

### Спайки

1. Fixed-point: hi/lo умножение и анализ диапазонов
2. Детерминизм: идентичные хеши на трёх ОС
3. ~~60 FPS на Steam Deck~~ — перенесён в 0.2.0. Мерить нечего, пока на экране четыре квадрата: замер на Canvas 2D ничего не скажет о WebGL2-рендере, ради которого он и затевается

### Проверка

```bash
npm run check       # линт, типы, границы модулей, палитра
npm test            # юнит + golden-реплеи + сценарии + аллокации
npm run sim -- --determinism-check --seeds 100
npm run bench
```

> **🚪 Ворота.** Детерминизм доказан на трёх ОС. Агент запускает, шагает и читает состояние игры без единого клика. Обновление сборки подхватывается перезагрузкой. Дальше не идём — детерминизм невозможно добавить позже.

## 0.2.0 «Тир»

**Цель:** доказать, что в бой приятно играть сам по себе. Самые важные ворота проекта.

### Бой [Я]

- Игрок: движение с инерцией, стрельба 6.5/с, рывок (240 u за 0.16 с, i-frames 0.22 с, кулдаун 1.2 с), 3 сердца, i-frames после урона 1.0 с
- Снаряды: пул, коллизии, время жизни
- Прощающая коллизия: хитбокс 18 u против визуальных 22 u
- Враги **Клин**, **Кирпич**, **Фитиль** с автоматами состояний и телеграфами ([DIFFICULTY.md §7](DIFFICULTY.md))
- Бюджетная система волн
- Одна арена с колоннами
- Правила честности: не спавнить ближе 250 u, метка при спавне вне поля зрения, не больше 3 телеграфов на игрока

### Сочность [К] — входит в ворота

- **WebGL2-рендер с батчингом** взамен Canvas 2D: без него частицы и вспышки не вытянуть
- Хитстоп: 20 мс попадание, 40 мс убийство, 70 мс урон игроку
- Тряска камеры по таблице ([GDD §6](GDD.md))
- Вспышки попаданий, squash-and-stretch, глаза следят за прицелом
- Частицы: смерть врага, попадание, дроп фишек с отскоком
- Рэгдолл-отброс с кувырком
- **Фотосенситивный порог сразу:** без полноэкранных строб, вспышки ≤3 Гц

### Аудио [К]

- Процедурный синтез в Web Audio: выстрел, попадание, смерть, подбор
- Ноль ассетов — настройка правкой числа

### Тесты [Т]

- Автомат каждого врага: все переходы, длительность телеграфа
- Рывок: i-frames спасают от снаряда, кулдаун соблюдается
- **Достижимость безопасной точки** на каждом тике
- Дистанция спавна, потолок телеграфов
- Ботовые прогоны: 500 забегов `random` без зависаний
- Нагрузочный бенч рендера: 2000 частиц + 200 болванок в бюджете кадра
- Спайк: 60 FPS на Steam Deck (прокси-замер в браузере) — переехал из 0.1.0 вместе с WebGL2

### Процесс

- Плейтест-канал из 5–10 человек заводится с этой версии
- Первое внешнее арт-ревью

### Проверка

```bash
npm run sim -- --bot random --runs 500 --json
npm run sim -- --scenario tests/scenarios/dash-iframes.json
npm run bench
```

> **🚪 Ворота (самые важные в проекте).** В бой приятно играть **пять минут без единой ставки**. Проверяется человеком, не ботом. Если скучно — чиним бой; ставки его не спасут, они его замаскируют, и мы узнаем правду на релизе.

## 0.3.0 «Ставка»

**Цель:** ставки живут внутри боя и ощущаются своим решением, а не заданием.

### Карты пари [Я]

- Карта как сущность симуляции: позиция, категория, владелец, оставшиеся тики
- Раскладка **`N` персональных + 2 общих**, разнесённо по арене
- Подбор **подтверждением кнопкой**, не наездом
- Детерминированное разрешение одновременного подбора
- Карта тает за 720 тиков, предупреждение за 180
- Подброс карты Тузом в середине боя — чистая функция от состояния
- Лимит активных пари: 4 на игрока

### Механика ставок [Я]

- Шесть пари★: без урона, без рывка, быстрее 45 с, не заходи в красную зону, собери все фишки, подрывник
- **Прогресс `q`** для каждого пари ([ECONOMY.md §9А](ECONOMY.md))
- «Забрать»: `кон × (1 + q × (M−1)/2)`, командные не обналичиваются
- Аппетит на экране двери, три тира
- Кон списывается за каждую карту, не превышает кошелёк
- Расчёт: выплата, провал, **near-miss**
- Матрица конфликтов пари, матрица «пари × схема ввода»

### Туз [К]

- Появление на арене, слой ниже боевых сущностей, полупрозрачность при перекрытии
- Телеграф подброса 0.5 с, без коллизии и уязвимости
- Система контекстных барков
- **Жесты:** зевает, аплодирует, отворачивается, нервничает ([GDD §17А](GDD.md))

### Интерфейс [К]

- HUD активных пари с «дыханием» и растущей потенциальной выплатой
- Глиф «Забрать» рядом с кушем
- Карты: кремовая подложка, иконка категории, вертикальный луч
- **ΔE-проверка** пар «карта / игрок / фишка / враг / телеграф»
- Экран расчёта с near-miss

### Аудио [К]

- Подбор карты (шелест колоды, не «монетка»), «Забрать» (кассовый аккорд), появление Туза, подброс, угасающий звон

### Данные [Д]

- Пари описываются JSON со схемой Zod, не кодом

### Тесты [Т]

- Каждое из шести пари: **засчитывается когда должно, проваливается когда должно**
- Прогресс `q` корректен для каждого
- «Забрать»: формула, `q=0` возвращает только кон
- Раскладка: количество, честность, персональные карты недоступны чужим
- Визуальная регрессия: стресс-кадр в `stable()`

### Проверка

```bash
npm run sim -- --scenario tests/scenarios/bets/*.json
npm run sim -- --runs 500 --bot greedy --json
```

> **🚪 Ворота.** Плейтестер без подсказки берёт вторую карту и говорит «ещё разок». **Не-боевые экраны — меньше 20% времени комнаты.** Хотя бы одна смерть за сессию случается по дороге за картой: риск читается как свой, а не навязанный.

## 0.4.0 «Забег»

**Цель:** полный цикл от меню до итогов, и первый автобалансировщик.

### Структура забега [Я]

- Восемь комнат, выбор из 2–3 дверей, типы дверей
- Босс **Рулетка**: три фазы, встречные ставки, вращающаяся арена
- Магазин: шесть апгрейдов, цены по формуле
- **Доля заведения** в конце этажа
- **Торг с Тузом** при нехватке: три варианта ([GDD §12А.2](GDD.md))
- **Ставка Туза** — он ставит против игрока из своего кармана
- Долг и проклятия: не стакаются, обязательный трамплин после провала
- Экран итогов, смерть, победа

### Генерация [Я]

- Двенадцать шаблонов арен с зеркалированием и поворотом
- Кривая сложности по бюджету угрозы
- Правило ввода новых врагов: не чаще одного типа за две комнаты

### Автобалансировщик [И]

- **Абстрактная модель комнаты** с калибровкой по полной симуляции
- Профили ботов: навык × стратегия
- Ограничители **G1–G10, G12–G14, D1–D10**
- Первый эволюционный поиск оптимума
- `npm run balance` с человекочитаемым отчётом

### Инфраструктура [Ф]

- i18n-словарь RU + EN, **хардкод строк запрещён линтером**
- Телеметрия: простой ingest на VPS + Sentry, согласие игрока
- Баг-репорт в один клик с логом инпутов
- Миграции сохранений с версионированием

### Тесты [Т]

- Босс: все переходы фаз, встречная ставка
- Долг: не стакается, трамплин обязателен
- Торг: все три варианта работают
- Миграции: каждая пара версий открывается
- Навигация геймпадом: каждый элемент достижим, нет тупиков фокуса
- Локализация: нет захардкоженных строк, все ключи во всех языках

### Проверка

```bash
npm run sim -- --runs 1000 --bot mixed --json
npm run balance
```

> **🚪 Ворота.** Полный забег 12–18 минут. Больше 60% плейтестеров начинают второй добровольно — **проверяется на соло-забеге**. ≥95% берут пари добровольно (синхронно с G6). Ограничители зелёные.

## 0.5.0 «Диван» — первый публичный выпуск

**Цель:** кооп, который производит крики на диване.

### Кооп [Я]

- 1–4 игрока, drop-in удержанием кнопки с подтверждающей плашкой
- Арена растёт на +8% за игрока, столкновения игроков
- Масштабирование: угроза `×(1+0.8(N−1))`, доля заведения `×(1+0.6(N−1))`, базовая выплата `×(0.5+0.5/N)`
- **Распределение агро:** потолок 40% врагов на игрока, пониженный вес после воскрешения
- Ставки на напарника (без согласия) и на команду с растущим множителем
- Воскрешение удержанием у тела
- **Дух:** полёт, видимость скрытого, пинги, ставки на живых включая ставки против
- Общая доля заведения, штраф при неуплате — всей команде

### Социальный слой [К]

- Колесо пингов, эмоции на крестовине
- Общий HUD: свои пари крупно, чужие сжатыми иконками у краёв
- Лобби «только друзья» по умолчанию, выключатель ставок против напарника
- **Кнопка сохранения клипа** последних 15 секунд

### Визуал и аудио [К]

- Цвета игроков, базовая косметика для различения
- Первый настоящий музыкальный трек, голос Туза тарабарщиной
- Ползунок интенсивности вспышек

### Выпуск [М][Ф]

- Бесплатно на **`die.samoy.love`** и на itch.io, ссылка друзьям
- Discord и девлог
- Посты в r/roguelites, r/IndieGaming, r/couchcoop, DTF
- Первые видео кооп-фейлов в TikTok/Shorts
- Базовые лимиты запросов на публичных endpoint'ах

### Тесты [Т]

# Принципы

1. Ворота не пройдены — следующая версия не начинается. Особенно 0.2.0.
2. Каждая минорная версия — играбельная сборка с тегом и заметками.
3. Сценарии и golden-реплеи только накапливаются. Новая механика без сценария — незакрытая работа.
4. Публичный выпуск с 0.5.0: фидбек и вишлисты копятся заранее, а не в день релиза.
5. Контент режется, механики — нет.
6. Автоматика доказывает, что игра работает. Что в неё интересно играть — доказывает только человек.

# Double or Die — глоссарий

_Единственный источник истины по именам. Если термин где-то написан иначе — прав этот файл._

**Правило:** новое имя попадает сюда **до** того, как окажется в коде или другом документе.

---

## 1. Проект

| RU                | EN              | Значение                                                                                                                 |
| ----------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **Double or Die** | _Double or Die_ | Название игры. Не переводится ни на один язык. Тройной смысл: удвоить или ничего · пермасмерть · _die_ — игральная кость |
| **Забег**         | _Run_           | Одна попытка: 3 этажа, **15 минут** (рабочий коридор 12–18)                                                              |
| **Этаж**          | _Floor_         | 8 комнат + босс. Всего три                                                                                               |
| **Комната**       | _Room_          | Один бой, 35–105 секунд                                                                                                  |
| **Тик**           | _Tick_          | 1/60 секунды. **Все игровые тайминги задаются в тиках**, не в секундах                                                   |
| **Сид**           | _Seed_          | Число, порождающее весь забег детерминированно                                                                           |

**Канонический слоган:** «Чем наглее пари — тем жирнее куш.» · _The bolder the bet, the fatter the pot._
**Адрес игры:** `die.samoy.love` (nightly — `dev.die.samoy.love`)
**Жанр:** твин-стик роглайт про азарт. _Push-your-luck_ — только в англоязычных материалах.

## 2. Персонажи

| RU          | EN      | Значение                                                                                                                                                                                                                   |
| ----------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Туз**     | _Ace_   | Маскот, ведущий и **второй игрок за столом**. Выкладывает карты пари, ставит против игрока, торгуется, помнит привычки. Парящий цилиндр с глазами и белыми перчатками, туз на тулье. Склоняется: Туза, Тузу, Тузом, о Тузе |
| **Желешка** | _Blob_  | Персонаж игрока: капля с большими глазами                                                                                                                                                                                  |
| **Дух**     | _Ghost_ | Умерший в коопе. Летает, видит скрытое, пингует, **ставит на живых** — в том числе против них                                                                                                                              |

> Слово «Туза» допустимо только как редкое родовое пояснение в описаниях («Туз — Туз этого заведения»), никогда как имя.

## 4. Ставки

| RU               | EN           | Значение                                                                                                                                                       |
| ---------------- | ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Пари**         | _Bet_        | Условие, которое игрок берётся выполнить за множитель. Всего 24                                                                                                |

| **Стак**         | _Stack_      | Несколько пари сразу: множители перемножаются, выполнить нужно все                                                                                             |
| **Забрать**      | _Cash Out_   | Досрочное обналичивание своего пари. Командные обналичить нельзя                                                                                               |
| **«Удвоим?»**    | _«Double?»_  | Предложение поднять ставку вдвое ценой лишней волны                                                                                                            |
| **Почти**        | _Near miss_  | Показ, насколько близко было к победе при провале                                                                                                              |
| **Трамплин**     | _Leg Up_     | Гарантированно лёгкое пари после провала                                                                                                                       |
| **Ставка Туза**  | _Ace's Bet_  | Пари, которое Туз заключает против игрока из своего кармана                                                                                                    |
| **Одиночка**     | _Loner_      | Соло-карта с повышенным множителем. Компенсирует отсутствие кооп-множителей и даёт соло четвёртую карту для потолка                                            |
| **Красная зона** | _Red zone_   | Размеченный участок арены для пари «Не заходи в красную зону». Урона не наносит и рисуется, только пока это пари лежит картой или активно ([GDD §9.5](GDD.md)) |

## 13. Как это называет Туз

Рабочий словарь для того, кто пишет двести реплик: официальный термин и его версия голосом персонажа. Игра говорит правой колонкой, документация — левой.

| Термин           | Голосом Туза                          |
| ---------------- | ------------------------------------- |
| Доля заведения   | «мои скромные накладные расходы»      |
| Забрать          | «соскочить»                           |
| Долг             | «наше маленькое недоразумение»        |
| Последняя сделка | «ещё одна раздача, за счёт заведения» |
| Ключи            | «сувениры»                            |
| Фишки            | «мои фишки, временно у вас»           |
| Дух              | «наблюдатель без права голоса»        |
| Проклятие        | «условия пересмотрены»                |
| Провал пари      | «переоценка собственных сил»          |
| Потерянные фишки | «внесено добровольно»                 |
| Время в игре     | «часов у моего стола»                 |
| Смерть игрока    | «клиент закончился»                   |
| Ставка Туза      | «дружеское пари»                      |

Экран «Счёт с Тузом» подписан **правой** колонкой: не «потеряно фишек», а «внесено добровольно». Данные настоящие, интонация чужая — юмор берётся из столкновения, а не из шутки.

## Правила именования

1. **Одно понятие — одно слово** во всех документах. Синонимы запрещены.
2. **Имя объясняет себя за секунду.** Нужно описание, чтобы понять имя, — имя плохое.
3. **Никаких калек.** Русское имя — русское слово или осмысленный неологизм, не транслитерация.
4. **Имена не путаются** ни на слух, ни в списке.
5. **Название игры не переводится** ни в одном материале.
6. **Реплики Туза пишутся без родовых форм.** Не «ты повернул», а «Налево. Опять налево». Половина аудитории — не «пришёл», и в семи языках локализации согласование сломается.
7. **Условие на карте — не длиннее 28 знаков** в русском исходнике; макет держит +40% под немецкий.
8. **Юмор играется телом, а не текстом.** Шутки в интерфейсе стареют и плохо переводятся; поведение Туза работает без слов ([GDD §17А](GDD.md)).
9. **Ни одной шутки в обучающих подсказках.** Там текст должен работать, а не веселить.

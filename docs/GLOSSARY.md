# Double or Die — глоссарий

_Единственный источник истины по именам. Если термин где-то написан иначе — прав этот файл._

**Правило:** новое имя попадает сюда **до** того, как окажется в коде или другом документе.

## 4. Ставки

| RU                  | EN                 | Значение                                                                                                                                                       |
| ------------------- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Пари**            | _Bet_              | Условие, которое игрок берётся выполнить за множитель. Всего 24                                                                                                |
| **Карта пари**      | _Bet card_         | Физический предмет на арене. Подбирается в бою                                                                                                                 |
| **Кон**             | _Stake_            | Поставленная сумма. Никогда не превышает кошелёк                                                                                                               |
| **Аппетит**         | _Appetite_         | Размер кона: **Скромно / Нормально / По-крупному** (_Modest / Normal / Go Big_). Задаётся одним нажатием и держится всю комнату                                |
| **Множитель**       | _Multiplier_       | Во сколько раз выплачивается кон. Безубыточность: `p = 1/M`                                                                                                    |
| **Сборка**          | _Stack_            | Несколько пари сразу: множители перемножаются, выполнить нужно все                                                                                             |
| **Забрать**         | _Cash Out_         | Досрочное обналичивание своего пари. По умолчанию — самое выгодное активное; командные обналичить нельзя                                                       |
| **Поштучный забор** | _Focused Cash Out_ | Настройка доступности (выкл. по умолчанию): «Забрать» берёт не самое выгодное, а выбранное крестовиной ← → пари ([UX §5](UX.md))                               |
| **«Удвоим?»**       | _«Double?»_        | Предложение поднять ставку вдвое ценой лишней волны                                                                                                            |
| **Почти**           | _Near miss_        | Показ, насколько близко было к победе при провале                                                                                                              |
| **Трамплин**        | _Leg Up_           | Гарантированно лёгкое пари после провала                                                                                                                       |
| **Ставка Крупье**   | _Ace's Bet_        | Пари, которое Крупье заключает против игрока из своего кармана                                                                                                 |
| **Одиночка**        | _Loner_            | Соло-карта с повышенным множителем. Компенсирует отсутствие кооп-множителей и даёт соло четвёртую карту для потолка                                            |
| **Красная зона**    | _Red zone_         | Размеченный участок арены для пари «Не заходи в красную зону». Урона не наносит и рисуется, только пока это пари лежит картой или активно ([GDD §9.5](GDD.md)) |

**Встречная ставка** _(Counter-bet)_ — пари, которое заключает **босс**, и единственное в игре, где ставка идёт не в фишках, а в боевой валюте: выиграл босс — лечится, сорвал игрок — босс оглушён ([GDD §8.1](GDD.md)). Не путать со **Ставкой Крупье**: та идёт фишками и заключается вне боя с боссом.

> «Ставка» — только как действие («поставить»). Как синоним пари не употребляется.

## 13. Как это называет Крупье

Рабочий словарь для того, кто пишет двести реплик: официальный термин и его версия голосом персонажа. Игра говорит правой колонкой, документация — левой.

| Термин           | Голосом Крупье                        |
| ---------------- | ------------------------------------- |
| Доля заведения   | «мои скромные накладные расходы»      |
| Забрать          | «соскочить»                           |
| Долг             | «наше маленькое недоразумение»        |
| Последняя сделка | «ещё одна раздача, за счёт заведения» |
| Ключи            | «сувениры»                            |
| Фишки            | «мои фишки, временно у вас»           |
| Дух              | «наблюдатель без права голоса»        |
| Проклятие        | «условия пересмотрены»                |
| Провал пари      | «переоценка собственных сил»          |
| Потерянные фишки | «внесено добровольно»                 |
| Время в игре     | «часов у моего стола»                 |
| Смерть игрока    | «клиент закончился»                   |
| Ставка Крупье    | «дружеское пари»                      |

Экран «Счёт с Крупье» подписан **правой** колонкой: не «потеряно фишек», а «внесено добровольно». Данные настоящие, интонация чужая — юмор берётся из столкновения, а не из шутки.

## Правила именования

1. **Одно понятие — одно слово** во всех документах. Синонимы запрещены.
2. **Имя объясняет себя за секунду.** Нужно описание, чтобы понять имя, — имя плохое.
3. **Никаких калек.** Русское имя — русское слово или осмысленный неологизм, не транслитерация.
4. **Имена не путаются** ни на слух, ни в списке.
5. **Название игры не переводится** ни в одном материале.
6. **Реплики Крупье пишутся без родовых форм.** Не «ты повернул», а «Налево. Опять налево». Половина аудитории — не «пришёл», и в семи языках локализации согласование сломается.
7. **Условие на карте — не длиннее 28 знаков** в русском исходнике; макет держит +40% под немецкий.
8. **Юмор играется телом, а не текстом.** Шутки в интерфейсе стареют и плохо переводятся; поведение Крупье работает без слов ([GDD §17А](GDD.md)).
9. **Ни одной шутки в обучающих подсказках.** Там текст должен работать, а не веселить.

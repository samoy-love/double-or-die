# Double or Die — управление, интерфейс, доступность

---

## 1. Принципы

1. **Одинаково хорошо с геймпадом и без.** Не «геймпад основной, клавиатура как-нибудь». Обе схемы проектируются как первоклассные.
2. **Ноль обучающего текста.** Всё объясняется действием, формой и репликой Туза.
3. **Опасным должен быть поступок, а не интерфейс.** Тянуться за картой в простреливаемый угол и погибнуть — история; погибнуть, читая меню под обстрелом, — дизайн-ошибка. Поэтому в бою живут только решения, читаемые мгновенно (цвет и иконка карты) и нажимаемые одной кнопкой; всё, что требует чтения и сравнения, — на паузе или в слоу-мо.
4. **Между комнатами — один экран.** Выбор двери с аппетитом, и сразу в бой; ставки делаются внутри схватки.
5. **Доступность — не режим для избранных, а набор ползунков для всех.** Тряску экрана убавляют не только люди с вестибулярными нарушениями.

## 2. Схемы управления

### Геймпад (основная)

| Действие              | Кнопка                           |
| --------------------- | -------------------------------- |
| Движение              | левый стик                       |
| Прицел                | правый стик                      |
| Огонь                 | RT (удержание = автоогонь)       |
| Рывок                 | **A** (только A — LB занят)      |
| **Подобрать карту**   | X, когда стоишь на карте         |
| **«Забрать»**         | **LB**, короткое удержание 0.3 с |
| **Рассмотреть карту** | удержание RT на карте            |
| Принять «Удвоим?»     | Y                                |
| Отказаться            | B                                |
| Воскресить напарника  | удержание **X** у тела, 3 с      |
| Колесо пингов         | удержание RB                     |
| Эмоции                | крестовина                       |
| Пауза / меню          | Start (**везде и всегда**)       |

**Три правила ввода:**

1. **Рывок только на A.** LB занят обналичиванием: если повесить рывок и на него, каждый уворот сжигал бы ставку.
2. **Карта не подбирается наездом.** Наезд подсвечивает карту, принятие — нажатием X. Иначе уворот рывком навязывал бы нежеланное пари и ломал бы «Шулера», магнит фишек и пари «Не подбирай ничего». Побочная выгода: подтверждение — дискретное событие, что даёт сети однозначное разрешение гонки за карту.
3. **Короткое удержание на «Забрать».** Случайное нажатие не должно сжигать куш.

**Аппетит** выбирается заранее, на экране двери: крестовина ↑↓, одно нажатие на всю комнату.

**Дух:** LS — полёт, RT — пинг-подсветка, A — ставки Духа, удержание X у своего тела — самовоскрешение.

### Клавиатура и мышь (равноправная)

Движение WASD, прицел мышью, ЛКМ — огонь, Space/ПКМ — рывок, `E`/`Q` — принять/отказ, `V` — пинги (не Tab: в браузере Tab уводит фокус со страницы), `1–5` — эмоции, `Esc`/`P` — пауза (в веб-сборке Esc выбивает из fullscreen и снимает pointer lock — дубль на `P` обязателен).

**Ставки на КБМ:** `X` — подобрать карту, `Shift` — «Забрать», `E`/`Q` — ответ на «Удвоим?», удержание `F` — рассмотреть карту (не `Alt` — он уводит фокус в меню браузера и ОС), удержание `X` — воскресить. Аппетит на экране двери — колесо или `1/2/3`.
Прицел мышью объективно точнее стика — **это не баг, а причина не делать соревновательный онлайн-versus смешанным по устройствам ввода без разделения таблиц**.

### Только клавиатура

Полноценная схема, а не сноска: WASD — движение, стрелки — прицел, `Ctrl`/`.` — огонь, `Space` — рывок, `X` — подобрать карту, `Shift` — «Забрать», удержание `F` — рассмотреть, `E`/`Q` — принять/отказ на «Удвоим?», удержание `X` — воскресить, `V` — пинги, `1–5` — эмоции, `P`/`Esc` — пауза, `Z` — аппетит на экране двери. По умолчанию включён **лёгкий авто-прицел**.

### Тач (веб и мобильные)

Виртуальные стики с плавающей точкой касания, автоогонь по умолчанию плюс кнопка временного прекращения огня. Справа снизу — рывок; **карта берётся тапом по подсказке**, когда стоишь на ней; **«Забрать»** — тап по карточке пари в HUD; удержание карточки — рассмотреть; «Удвоим?» — две крупные кнопки; воскрешение — удержание тапа у тела; пинги и эмоции — колесо по свайпу вверх; пауза — кнопка в углу. Аппетит на экране двери — три крупные плитки.

Пари, требующие точного контроля выстрелов, на таче не выпадают (матрица «пари × схема ввода», [GDD §9.5](GDD.md)).

## 3. Ощущение управления

| Параметр                | Значение                                  | Зачем                                  |
| ----------------------- | ----------------------------------------- | -------------------------------------- |
| Мёртвая зона стика      | радиальная 0.18 с ремапом остатка в 0..1  | квадратная зона врёт на диагоналях     |
| Буфер ввода             | 6 кадров                                  | прощает раннее нажатие рывка           |
| Coyote-время рывка      | 4 кадра                                   | рывок «в последний момент» срабатывает |
| Задержка ввода локально | ≤ 2 кадра                                 | измеряется, входит в тесты             |
| Вибрация                | по событиям, ползунок 0–100%              |                                        |
| Автоприцеливание        | выкл / лёгкое (магнит 6°) / сильное (12°) | геймпад и клавиатура                   |

**Прощающая коллизия:** хитбокс игрока меньше видимой формы (радиус 18 u против визуальных 22 u). Игрок должен думать «я увернулся», а не «оно меня зацепило».

## 4. Интерфейс

Весь UI рендерится внутри игры (не DOM) — единый вид на всех платформах и корректная навигация геймпадом.

### HUD в бою

```
┌─────────────────────────────────────────────────────────┐
│ ♥♥♡  [🛡 Без урона ×3] [⏱ 0:32 ×2]  куш 320 ⟨LB⟩  💰 145│  ← HP, свои пари, текущий куш, кошелёк
│                                                          │
│                      АРЕНА                               │
│                                                          │
│ P2♥♥♥ P3♥♥♡ P4♥♡♡ (пари — сжатыми иконками)  Волна 2/3  │  ← напарники у краёв, прогресс
└─────────────────────────────────────────────────────────┘
```

- **Свои пари крупно сверху, чужие — сжатыми иконками у краёв.** При четверых со стаком видимых элементов не больше восьми; детали — по удержанию.
- **Карты пари «дышат»:** близко к провалу — дрожат, выполнено — золотятся.
- Прогресс пари виден численно там, где это счётчик («3/5 касаний»), и **растущей потенциальной выплатой** рядом с глифом «Забрать».
- В коопе пари всех игроков видны всем — это предмет общения.
- HUD не заслоняет края арены: играбельная зона отступает от краёв экрана.

### Правила читаемости

- Снаряды — самое яркое на экране, всегда.
- Опасные зоны — алые с пульсацией **и** штриховкой (двойное кодирование).
- Своего персонажа видно всегда: обводка цветом игрока + мягкий нимб + стрелка над головой в первые 2 секунды комнаты и после воскрешения.
- Минимальный размер текста — 24 px при 1080p (правило «читается с дивана в 2 метрах»).
- Ни одного модального окна с текстом длиннее строки.

## 5. Доступность

Полный набор — не «галочка для сторов», а реальное расширение аудитории. Все настройки доступны из паузы, не только из главного меню.

### Зрение

- **Три палитры дальтоника** (протан/дейтеран/тритан) поверх основного двойного кодирования формой.
- Ползунок размера интерфейса 100–150% (нижняя граница 100 — иначе нарушается собственное правило «минимум 24 px»).
- Опция шрифта для дислексии.
- Высококонтрастный HUD.
- **Ползунки эффектов по отдельности:** тряска камеры, вспышки, хроматическая аберрация, частицы, виньетка — каждый 0–100%.
- **Фотосенситивная безопасность — с первой публичной версии, а не в огранке.** Базовый порог (никаких полноэкранных строб, частота вспышек ≤3 Гц) — дефолт уже в 0.2.0, ползунок интенсивности вспышек — к 0.5.0; публичные версии с казино-эстетикой без этой защиты — риск здоровья, а не полировки. Полный «режим без мерцаний» и тонкая настройка — 0.12.0.
- **Палитры дальтоника** — базовая проверка пар «игрок/враг/фишка/телеграф» по ΔE ещё на стадии F2 (0.4.0), полные три профиля — 0.12.0.

### Слух

- Субтитры для всех реплик Туза с настройкой размера и фона.
- **Визуальный дубль всех звуковых сигналов:** сигнал пари «Танцор», предупреждение об атаке, окончание таймера — всегда имеют экранный эквивалент.
- Раздельные ползунки: музыка / SFX / голос Туза / интерфейс.

### Моторика

- Полный ремап всех действий, включая клавиатуру и геймпад.
- **Пресеты для одной руки** (левой и правой).
- Удержание ↔ переключение для огня, пингов, прицела.
- Автоогонь по умолчанию включаем на тач и предлагаем везде.
- Автоприцел трёх уровней.
- Отключение вибрации.

### Когнитивные

- **Режим «Спокойно»:** скорость игры 60–100% (соло и локальный кооп), удвоенное окно «Удвоим?», **удвоенное время жизни карты на арене** и замедленный темп подбрасывания карт Тузом. Экранов с таймерами в локальной игре нет вовсе — вся динамика живёт в бою.
- Подсветка «что от меня хочет пари» — иконка-подсказка над персонажем.
- Отключаемые «дурацкие» пари для тех, кому они мешают.
- Пауза везде, где это не ломает мультиплеер.

### Проверка

Чеклист доступности проходит на каждой минорной версии. В 0.12.0 — полный прогон по гайдлайнам Xbox Accessibility Guidelines и заполнение полей доступности на странице Steam (Valve их отображает, кураторы замечают).

## 6. Экраны

| Экран         | Правило                                                                                                                                               |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Главное меню  | одна крупная кнопка «Играть», остальное мельче                                                                                                        |
| Выбор режима  | появляется только после первого забега                                                                                                                |
| Выбор двери   | пауза; здесь же аппетит на всю комнату                                                                                                                |
| Магазин       | пауза, сравнение апгрейдов по наведению                                                                                                               |
| Расчёт        | 5 секунд; пропуск — `A`/`E` после задержки в 1 секунду, зажатый RT игнорируется (иначе автоогонь проскакивает near-miss — главный крючок «ещё разок») |
| Итоги забега  | «ролик-статистика», скриншотопригодный кадр, кнопка «Ещё раз» — первая и самая крупная                                                                |
| «Счёт с Туза» | статистика игрока ([GDD §19](GDD.md)): главное число — сальдо с заведением, блок «лучший куш» сделан под скриншот                                     |
| Настройки     | три вкладки: Игра / Управление / Доступность                                                                                                          |

**Кнопка «Ещё раз» всегда доминирует на экране итогов.** Цикл «ещё разок» — то, ради чего игра существует.

## 7. Онбординг

Подробно расписан в [GDD.md §22](GDD.md). Ключевое правило: **первая ставка бесплатна** — игрок пробует ядро игры без риска потерять что-либо, и урок «пари меняет то, как я играю» приходит через опыт, а не через текст.

## 8. Локализация

- Весь текст — через словарь начиная с 0.4.0. Хардкод строк запрещён линтером с той же версии.
- Объём: ~4 000 слов (мало — большая часть текста это короткие барки).
- **С 0.4.0:** английский, русский.
- **В 0.12.0:** упрощённый китайский (огромный рынок инди на Steam), немецкий, французский, испанский, португальский (Бразилия), японский.
- Голос Туз — тарабарщина, переозвучка не нужна ни для одного языка. Это экономит десятки тысяч долларов.
- Интерфейс проектируется под +40% длины строки (немецкий) и под иероглифы.
